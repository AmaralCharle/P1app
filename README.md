# Academy Notes

Aplicativo acadêmico em React Native com Expo para gerenciar notas, desempenho e alunos de forma visual e prática.

## Objetivo

Simular um sistema acadêmico simples sem banco de dados, com dados fictícios em memória para demonstrar lógica de aplicação, cadastro de alunos e cálculo de médias.

## Funcionalidades

- painel principal com resumo acadêmico
- cadastro de alunos
- seleção de aluno para registrar notas
- disciplina e nota por aluno
- cálculo automático de média
- status: aprovado, revisão ou atenção
- interface em React Native com visual moderno

## Tecnologias

- React Native
- Expo
- JavaScript

## Como executar

```bash
npm install
npx expo start
```

Para web:

```bash
CI=1 npx expo start --web
```

## Observação acadêmica

Este projeto foi montado como MVP (Produto Mínimo Viável) para apresentação universitária, com foco na experiência do usuário, lógica da aplicação e organização do código.

## Checklist para apresentação

- app híbrido
- React + Expo
- JavaScript
- sem banco de dados no momento
- dados simulados em memória
- interface funcional e navegável
- apresentação da lógica de notas e cálculos
